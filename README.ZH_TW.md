# Tile World

[English](README.md) | 繁體中文

卡牌 × 六角拼圖的放鬆小遊戲。從手牌挑地塊，一塊一塊拼出屬於自己的世界，玩到牌用完為止。
適合搭車時用手機單手玩，隨時可以中斷，每一步都會自動存檔，沒有網路也能玩。

## 特色

- 四個主題：浮島、台灣街景、海底、太空，每個主題有自己的景色與配樂
- 3D 低多邊形地圖，會有雲、鳥、船、魚、飛碟等小動態
- 同類型地形相接時，相連的區域會閃爍微光
- 撲克牌式的地塊卡，附發牌與翻牌動畫
- 支援繁體中文、日本語、English
- 可加入主畫面（PWA），離線也能玩

## 玩法

1. 點一張手牌，可以放的位置會亮起來
2. 點空格預覽，點預覽地塊或 ↻ 旋轉方向
3. 按 ✓ 放下，相接的邊地形相同就得分，六邊全吻合有額外加分
4. 牌堆與手牌都用完時遊戲結束

操作：單指拖曳移動、雙指縮放；電腦版可用滑鼠右鍵拖曳或 Q / E 旋轉視角。

## 技術

TypeScript、Vite、three.js、Web Audio（音樂音效即時合成）、Service Worker。
